Apograph — Frontend Cloning Engine

Crawl any public website. Get a deployable React project. Expect 70–85% fidelity and a few hours of polishing.

View on GitHub 
npx apograph-agents clone <url>

How it works

1

Crawl

Headless Chromium captures screenshots, accessibility trees, and design tokens from every page

2

Plan

A schema-validated plan is generated. You review and approve it before anything is synthesized.

3

Synthesize

A vision LLM writes React 19 + Tailwind CSS components from the evidence

4

Verify

3-tier verification: TypeScript build, route smoke test, and pixel-diff against the original screenshots

What to expect

Page structure & layout 90%
Color system & palette 92%
Typography 85%
Navigation 80%
Static content 75%
CSS animations 35%
JS-driven interactions 45%
Authenticated flows Not supported

These are realistic averages on typical company and portfolio sites. Animation-heavy sites, heavily JavaScript-driven SPAs, and sites behind authentication will need significantly more manual work.

Quick start

  1. 1. Install

    npm i -g apograph-agents

  2. 2. Clone a site

    apograph clone https://yoursite.com

  3. 3. Boot the result

    cd output/yoursite-com && pnpm install && pnpm dev
